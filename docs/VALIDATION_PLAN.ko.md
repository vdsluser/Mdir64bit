# 원본 실행 검증 절차

상태: 2026-10-20 작성, 실행 미수행. PATH 및 Program Files 최상위에서 DOSBox 계열을 찾지 못했다. 시스템 전체 미설치 판정은 아니다.

## 환경과 증거

1. 원본 `mdir/` 및 ZIP의 SHA-256을 인벤토리와 대조한다. 분석 도구·에뮬레이터 버전/설정·OS·코드페이지·키보드·마우스·외부 압축 도구 버전도 기록한다.
2. 로컬 `analysis-local/`에 원본의 작업 복사본과 합성 테스트 데이터만 둔다. 에뮬레이터에는 이 디렉토리만 마운트한다. 호스트 루트·실제 작업 자료·물리 디스크를 노출하지 않는다.
3. DOS 환경에서 기본 기능을 조사하고, 합법적으로 사용 가능한 Win95/DOS 7 환경을 별도로 준비해 긴 파일명·코드페이지·Windows 키 충돌을 확인한다. 환경이 없으면 해당 사례를 BLOCKED로 남긴다.
4. 기본 CFG와 사용자 제공 CFG를 별도 실행해 기본값과 사용자 정의를 구분한다. 등록 상태는 프로그램 정보 화면으로 확인하며 등록정보는 마스킹한다.
5. 증거는 `docs/evidence/<case-id>/`에 요약·스크린샷·키 입력 순서·파일 해시 차이를 기록한다. 원본 전문·개인정보가 포함된 캡처는 공개하지 않는다.

## 사례 형식

```text
사례 ID / 기능 ID / 문서 근거:
원본 SHA-256 / 환경 ID / 설정 SHA-256 / 등록 상태:
사전 디렉토리 구조 및 파일 내용 해시:
키·마우스 입력 순서:
설명서상 기대값:
실제 화면 / 파일 변화 / 오류 / 종료 코드:
취소 후 상태 / 재실행 후 상태:
판정: PASS | DIFF | BLOCKED | NOT-APPLICABLE
증거 경로 / 미해결 사항:
```

PASS는 관찰한 원본이 해당 사례의 기대와 일치한다는 뜻이다. Windows판 구현 통과와 구분한다. 기능마다 정상·취소·오류 사례를 분리하며 해당하지 않는 경우 이유를 쓴다.

## 실행 순서

| 묶음 | 시험 | 확인할 결과 |
|---|---|---|
| 기본 | 시작·종료·F1/F12·Alt/Ctrl 상태선·키보드/마우스·각 화면 크기 | 전체 메뉴 항목, 포커스, 뒤로가기·취소 상태 |
| 목록 | 모든 정렬/동률/열/필터/속성/선택/작업경로 | 선택 순서와 커서, 표시 개수·합계, 상태 유지 |
| 파일 | 복사·이동·삭제·일괄 이름·폴더·속성·인쇄 | 선택 대상 차이, 충돌 6정책, 용량 부족, 잠금, 취소·부분 실패 |
| 트리 | MCD 재검색·폴더 작업·용량·QCD 10개 | 캐시 생성/갱신, 존재하지 않는 즐겨찾기, CD/LAN별 저장 |
| 실행 | Enter/Tab/옵션/종료 후 실행/28키/복수 연결 | 작업경로·인자·메모리 실행 모드 차이·복귀 화면 |
| 입력 | CLI 대소문자·복합 옵션·우선순위·변수·이력 | 문자열 치환·선택 파일·경로 삽입·취소, 부모 셸 복귀 |
| 주석 | 입력·다중 편집·복사/이동/이름 변경·긴 이름 | DESCRIPT.ION 바이트 차이·길이 한계·인코딩·등록판 차이 |
| 압축 | 각 형식 읽기/쓰기/추출/삭제/SFX/잘못된 확장자 | 11형식별 결과, 도구 부재, 트리/평탄화·실행後 임시 정리 |
| 설정 | 추적표 SET 항목을 하나씩 변경·저장·재실행 | CFG/COL/VV 실행파일 변화, 예전 CFG 읽기, 저장 취소 |
| MFF/VV | 다중 패턴·중단·검색결과 작업·보기·문자 인코딩·이진 | 선택과 커서 대상, 한자/글꼴 부재, 표시 설정 보존 |
| 기타 | HCONV·HE·DSCMAN·드라이버·MF/MCOPY | 도움말/호출관계, 플로피 이미지 결과·오류·등록 제한 |

## 표본과 경계

빈 폴더·단일/다중 선택·동일 이름·동일 시간·크기·숨김/읽기전용/시스템·한글·공백·8.3 이름·긴 이름·중첩 폴더·읽기전용 매체를 준비한다. 원본 문서의 500/2000 파일, 2000 디렉토리, 1000 주석 한계 전후를 조절해 관찰한다. 2GB 부근 용량 표시는 업데이트 이력의 회귀 항목이다.

Windows판에서는 추가로 4GB 초과 파일, 긴 경로, Unicode 혼합/이모지, 접근 거부, 잠긴 파일, 네트워크 끊김, 정션 순환, 압축 경로 탈출을 시험한다. 이런 현대 환경 결과를 원본 지원 사실로 기록하지 않는다.

## P0 완료 체크

- 모든 기능 ID에 실행 사례 또는 차단/해당 없음 이유가 있다.
- 메뉴에서 새로 찾은 기능은 새 ID를 발급했다.
- 문서 간 모순과 판본 차이를 해소하거나 결정 필요 상태로 명시했다.
- 원본/작업본 해시, 환경 재현 절차, 증거가 연결되어 있다.
- 미검증 항목이 남으면 조사 완료나 완전 호환을 선언하지 않는다.
